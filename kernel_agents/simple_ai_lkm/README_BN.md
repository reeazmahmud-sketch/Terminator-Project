# লিনাক্স কার্নেল মডিউল (LKM) AI এজেন্ট

এটি একটি কার্নেল-স্পেস AI এজেন্টের প্রোটোটাইপ যা `/dev/ai_agent` ক্যারেক্টার ডিভাইসের মাধ্যমে লো-লেটেন্সি ইনফারেন্স প্রদান করে।

## ডিরেক্টরি গঠন
- **`ai_agent.c`**: মূল কার্নেল মডিউল কোড। ফিক্সড-পয়েন্ট ম্যাথ ব্যবহার করে নিউরাল নেটওয়ার্ক ইনফারেন্স করে।
- **`Makefile`**: কার্নেল মডিউল এবং ইউজার স্পেস ক্লায়েন্ট কম্পাইল করার জন্য।
- **`user_space_client.c`**: ইউজার স্পেস থেকে কার্নেল এজেন্টের সাথে যোগাযোগ করার টুল।

## মূল ফিচার
- **ফিক্সড-পয়েন্ট ইনফারেন্স**: কার্নেল স্পেসে ফ্লোটিং পয়েন্ট এড়াতে Q15 ফরম্যাট ব্যবহার করা হয়েছে।
- **IOCTL সাপোর্ট**: ওয়েট (Weight) লোড করার জন্য নিরাপদ `ioctl` ইন্টারফেস।
- **ডিভাইস ফাইল**: `/dev/ai_agent` এর মাধ্যমে রিড/রাইট অপারেশন।

## ডেপ্লয়মেন্ট নির্দেশনা

১. **প্রস্তুতি (Linux VM)**:
   প্রয়োজনীয় কার্নেল হেডার এবং টুলস ইনস্টল করুন:
   ```bash
   sudo apt install linux-headers-$(uname -r) build-essential
   ```

২. **কম্পাইল এবং লোড**:
   ```bash
   make
   sudo insmod ai_agent.ko
   ```

৩. **ডিভাইস নোড তৈরি**:
   অটোমেটিক তৈরি না হলে ম্যানুয়ালি তৈরি করুন:
   ```bash
   sudo mknod /dev/ai_agent c $(cat /proc/devices | grep ai_agent | awk '{print $1}') 0
   ```

৪. **টেস্টিং**:
   ক্লায়েন্ট টুল কম্পাইল করে রান করুন:
   ```bash
   make user_client
   sudo ./user_space_client
   ```

৫. **লগ এবং আনলোড**:
   কার্নেল লগ দেখতে:
   ```bash
   dmesg | grep "AI Agent"
   ```
   মডিউল রিমুভ করতে:
   ```bash
   sudo rmmod ai_agent
   make clean
   ```

## সতর্কতা
এটি কার্নেল লেভেলে রান করে, তাই কোডে ভুল হলে পুরো সিস্টেম ক্র্যাশ করতে পারে। প্রোডাকশন এনভায়রনমেন্টে ব্যবহারের আগে ভার্চুয়াল মেশিনে (VM) টেস্ট করা বাধ্যতামূলক।
