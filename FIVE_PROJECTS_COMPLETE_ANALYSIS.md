## 🚀 How to Use:

### Setup (One-time):
```bash
cd ~/Desktop/Eve
python3 -m venv .venv
source .venv/bin/activate
pip install mcp fastapi uvicorn pydantic
cp .env.example .env
cp gemini-config.example.json gemini-config.json
```

### Run Server:
```bash
# stdio mode (for Claude Desktop):
source .venv/bin/activate
python3 gemini_mcp_server.py --mode stdio --project-root /path/to/project

# HTTP mode (experiments):
python3 gemini_mcp_server.py --mode http
# Server at: http://localhost:8006
```

### Claude Desktop Integration:
Edit `~/Library/Application Support/Claude/claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "gemini": {
      "command": "python3",
      "args": [
        "/Users/reeazmahmud/Desktop/Eve/gemini_mcp_server.py",
        "--mode", "stdio",
        "--project-root", "/path/to/project"
      ]
    }
  }
}
```
