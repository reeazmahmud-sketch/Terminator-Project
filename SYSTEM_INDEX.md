## 🆘 TROUBLESHOOTING

### System Not Starting
1. Run health check:
   ```bash
   cd ~/Desktop/Terminator
   python3 PRE_TERMINATOR_HEALTH_CHECK.py
   ```

2. Check Ollama:
   ```bash
   ollama serve
   ```

3. Check port 8000:
   ```bash
   lsof -ti:8000 | xargs kill
   ```

### Dashboard Issues
1. Check monitor logs:
   ```bash
   tail -f ~/Desktop/AI/Ai\ \&\ Agents\ Dashboard/dashboard_monitor.log
   ```

2. Restart dashboard:
   ```bash
   ~/Desktop/AI/start_dashboard_with_monitor.sh
   ```

### Agent Health

