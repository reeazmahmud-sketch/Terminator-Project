# T.E.R.M.I.N.A.T.O.R Web Terminal

A futuristic, interactive landing page inspired by Iron Man's TERMINATOR interface. Built with React, Tailwind CSS, and Framer Motion.

## Features
- **Arc Reactor Core**: Animated CSS/Framer Motion component.
- **Interactive Terminal**: Type commands (try `help`, `status`, `scan`, `clear`).
- **System Metrics**: Visual representation of CPU/RAM/Network.
- **Dynamic Background**: Responsive grid and particles.
- **Sound Effects**: (Placeholder for future implementation).

## Setup & Run

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```

3.  **Build for Production**:
    ```bash
    npm run build
    ```

## Tech Stack
-   **React 18**
-   **Vite** (Build Tool)
-   **Tailwind CSS** (Styling)
-   **Framer Motion** (Animations)
-   **Lucide React** (Icons)
