# Core Personality Module

**Mission:** Serve as the central executive function, understanding user intent and coordinating the "Self".

## Agents
*   **TaskExecutorAgent:** The "Hands" – Executes approved plans.
*   **TaskPredictionAgent:** The "Intuition" – Anticipates user needs.
*   **ContextAwarenessAgent:** The "Memory" – Maintains conversational context.
*   **UserAdvocateAgent:** The "Conscience" – Ensures actions align with user best interests.

## Responsibilities
1.  **Intent Recognition:** Parsing natural language into executable tasks.
2.  **Context Management:** Maintaining state across long conversations.
3.  **User Advocacy:** Acting as the final safety check for user alignment.

## KPIs
*   **Intent Recognition Rate:** > 95%.
*   **Context Retention:** Ability to recall facts from > 10 turns ago.
*   **User Satisfaction:** Implicit or explicit positive feedback.
